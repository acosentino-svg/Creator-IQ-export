# Open the WBP compensation & tiers doc

The **`.html` file only works on your computer** if you have the repo folder (or you downloaded that file). It does **not** open from a random GitHub code view.

## Easiest options

### A — Copy/paste (no file)

Open **`COPY-PASTE-WBP-TIERS.txt`** in this folder. Copy all text into email, Google Doc, or Slack.

### B — Picture (phone)

Download **`WBP-COMPENSATION-TIERS.png`** from this chat’s **Artifacts** (not the PDF).

### C — Laptop with the repo

1. Go to folder `docs/boosting-monthly-brief/`
2. Double-click **`WBP-COMPENSATION-TIERS.html`**
3. It opens in Chrome/Safari/Edge. Use **Print → Save as PDF** if you need a PDF.

### D — GitHub in the browser (read without downloading)

Open **`COPY-PASTE-WBP-TIERS.txt`** on GitHub — the raw text displays in the browser.

Raw PNG (if your network allows):  
`https://github.com/acosentino-svg/Creator-IQ-export/raw/cursor/boosting-monthly-brief-cb1a/docs/boosting-monthly-brief/WBP-COMPENSATION-TIERS.png`

## Often fails

| Try | Why it fails |
|-----|----------------|
| Open `.pdf` from Mail on iPhone | iOS often won’t preview; use **PNG** or **.txt** |
| Click `.html` on GitHub | Shows source code, not the formatted page — use **B** or **C** |
| Old October file names | WBP doc is **`WBP-COMPENSATION-TIERS.*`** not `OCTOBER-ONE-PAGER` |
