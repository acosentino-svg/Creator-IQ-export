## What we need from you (creative standards)

Eligible WCP Elevate videos can be boosted as paid ads on **Meta and TikTok**. We only boost posts that feel like **creator content**, not commercials.

| | Guideline |
|---|-----------|
| **Format** | **Vertical video** (Reels / TikTok). **15–45 seconds.** Not a carousel for boosting. |
| **Hook** | In **1–3 seconds**: problem, benefit, or discovery + **product visible**. |
| **Creator** | Face-to-camera, hands-on, or POV — you’re in the frame for trust and demo. |
| **Product** | **Wayfair product, clear and early**, shown **in use in a real, styled space** (not unboxing-only). One clear benefit or use case. |
| **Pacing** | Brisk, easy to follow; fewer flashy cuts; hold shots long enough to see the product. |
| **Sound off** | **Captions** (especially Meta). Simple on-screen text; readable fonts; on screen long enough. |
| **Tone** | Informal, native, bright, lived-in — not a TV spot. |
| **Evergreen** | Seasonal *moments* are fine; **sale/promo-led** creative is not our main boost pool. |

**Program tags (eligibility):** Include **`#WayfairCreator`** and **`#wayfairelevate`** in the caption (case-insensitive). Follow disclosure rules you use for partnered content (e.g. `#ad` when required); eligibility is driven by the program hashtags above.
