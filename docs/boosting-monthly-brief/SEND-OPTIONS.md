# October boosting — three send options

Pick one per month or combine A + C (image in email + PDF).

---

## Option A — Canva one-pager (visual, scannable)

**Best for:** Creators who open on phone; looks polished in inbox if you embed the image.

**You send:**
- **Image or PDF:** `October-Canva-One-Pager.png` or `.pdf` (import into your Canva template if you prefer)
- **Optional one line in email:** “Full checklist attached as image — hashtags and length below.”

**Attach / embed:** PNG (inline in email) or PDF  
**Source file to edit:** `2026-10-october-canva-onepager.html` → open in browser → Print to PDF, or import PDF into Canva

**Includes:** October overview (bullets), messaging (4), deliverables, film ideas, great fits / skipped, appendix links

---

## Option B — Short brief only (text)

**Best for:** Quick ping, Slack, or creators who ignore attachments.

**You send:** Copy from `SHORT-BRIEF-OCTOBER-2026.md` (no attachment).

**Includes:** Priorities + creative bar + hashtags + contact  
**Does not include:** Examples, FAQ, detailed ideas

---

## Option C — Email + 2-page PDF (recommended for “full” email)

**Best for:** Default **email** send with complete info.

**You send:**
- **Body:** `EMAIL-OCTOBER-2026.md` (summary)
- **Attachment:** `October-Boosting-Brief-2-PAGES.pdf`

**Includes:** Everything in Option A plus FAQ, survey note, more examples

---

## Quick comparison

| | A One-pager | B Short text | C 2-page PDF |
|--|-------------|--------------|--------------|
| Length | 1 visual page | ~12 lines | 2 pages |
| Meta/TikTok priorities | ✓ | ✓ | ✓ |
| Examples & FAQ | Links only | ✗ | ✓ |
| Great fits / skipped | ✓ | ✗ | ✓ |
| Works in Canva | ✓ import | ✗ | Optional attach |

**Suggested default for email:** **Option C** (body from short brief + 2-page PDF).  
**Add Option A** as an inline image if you want a “poster” without reading the PDF.
