# How to open the October boosting brief

You do **not** need GitHub or a special PDF app if one of these works for you:

## Easiest: open the web page, then print to PDF

1. On your computer, open this folder in the project:  
   `docs/boosting-monthly-brief/`
2. **Double-click** `2026-10-october.html` (opens in Chrome, Edge, or Safari).
3. Press **Ctrl+P** (Windows) or **Cmd+P** (Mac).
4. Destination: **Save as PDF** → Save.

The `hero-bedroom.jpg` file must stay in the **same folder** as the HTML (it already is).

## If you have the PDF

- File: `Wayfair-Boosting-Brief-October-2026.pdf` (same folder).
- Try opening with **Chrome** or **Edge** (drag the file into the browser window).
- On Mac: **Preview** should open it.

## From the Cursor agent run

  - `October-Boosting-Brief-OPEN-THIS.png` (picture of the full page), or
